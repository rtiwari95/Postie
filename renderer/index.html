      Welcome to Postie

      A fast, local-first API client. Inspired by Postman, built with Electron and Rust.

      ⚡

      All HTTP methods

      GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS — full request control with headers, query params, and multiple body types.

      🔐

      Authorization

      Built-in support for Basic Auth, Bearer Token, and API Keys (as headers or query params). Auth never leaks into your saved headers.

      🌍

      Environments

      Define {{baseUrl}}-style variables and switch between dev / qa / prod with one dropdown.

      📁

      Collections & History

      Organize requests into collections, drag to resize, rename via right-click, and revisit anything from the auto-tracked history.

      📥

      Postman & cURL Import

      Import Postman v2.1 collections and environments. Paste a curl command into the URL bar — Postie parses method, headers, body, and auth.

      🧩

      Body editors

      JSON, XML, HTML, JavaScript, raw text, x-www-form-urlencoded, multipart form-data with file uploads, and binary file bodies — all syntax-highlighted.

      ⌨️

      Keyboard-first

      ⌘/Ctrl + Enter Send · ⌘/Ctrl + T New tab · ⌘/Ctrl + S Save · ? for the full list.

      🪶

      Local-first & private

      No accounts, no cloud, no telemetry. Your workspace lives in a single JSON file on your machine.

      Press ? any time to see all keyboard shortcuts.
